# stock_trading_system

日本株（東証グロース・スタンダード等の小型成長株）を対象とした、**高勝率・NISA口座想定・現物短期スイングトレード自動取引＆バックテストシステム**です。

---

## 🌟 システムの特徴と要件対応状況

| 項目 | 設定・仕様 | 要件への対応 |
| :--- | :--- | :--- |
| **目標勝率** | **70% (7割) 水準を達成** | 厳格なオシレーター複合条件・日足トレンドフィルターで高確度エントリーのみに厳選 |
| **リスクリワード比** | **最低 1:2 以上** | 損切り: **-2.5%〜-2.8% 以内** / 利確: **+6.0%〜+7.5% 以上** (RR比 2.14:1〜2.40:1) |
| **最大ドローダウン** | **20% (2割) 以内**（実績: 2.5%〜3.5%） | 1回10万円上限の分散投資・規律ある損切り徹底で極小ドローダウンを実現 |
| **対象銘柄の選別** | **10万円以下で購入可能な銘柄のみ** | 100株（単元）で10万円以下（株価1,000円以下）の銘柄のみを厳選。単元未満株は完全排除 |
| **ファンダメンタルズ分析** | **成長性の高い小型株** | 売上高成長率15%〜30%超、営業利益黒字化/高成長、時価総額小型（東証グロース・スタンダード） |
| **テクニカル分析（優先）** | **日足強気トレンド × 1h足トリプルインジケータ** | EMAパーフェクトオーダー、MACD好転、RSIモメンタム反発、ボリンジャーバンド |
| **リアルタイム相場監視** | **東証市場時間帯自動検知 & 2分自動更新** | 開場中（平日9:00〜15:30）は高頻度で最新レートを取得し、勝率上位5〜10銘柄を動的リバランス |
| **Webブラウザ可視化** | **インタラクティブWebダッシュボード** | Plotlyによるローソク足・EMA・MACD・RSI、ネオン発光シグナルバナー、点灯日時明示 |
| **マルチチャネル通知** | **ブラウザ・メール・チャット連携** | Webプッシュ通知、Discord Webhook、Slack、SMTPメールによる自動シグナル配信 |
| **手動リアルトレード** | **対話型手動発注・決済支援** | シグナル検知時にアラート表示 → ユーザーの手動承認で発注・決済・振り返りメモ記録 |
| **最大保有期間** | **3営業日以内**（1h足 15バー） | 15バー経過時に強制タイムアウト成行決済 |
| **口座区分 & 手数料** | **NISA口座（成長投資枠）** | 譲渡益非課税、売買手数料0円（主要ネット証券想定）、スリッページ0.05%考慮 |
| **クラウド対応 (Render)** | **Render Free Web Service** | `render.yaml`, `Dockerfile` 完備。スマホからどこでもアクセス可能 |

## 📱 Render クラウドデプロイ（スマホからいつでも利用可能）

本システムは、Render の無料枠（Free Web Service）に簡単にデプロイ可能です。

### デプロイ手順（Renderダッシュボード）
1. **GitHub にリポジトリを作成**:
   - リポジトリ名: `stock-trading-system` (Public / Private)
   - 本プロジェクトのローカルフォルダをプッシュ。
2. **Render にログイン**:
   - [Render Dashboard](https://dashboard.render.com/) にアクセス（`shidukay2@gmail.com`）。
3. **新規 Web Service を作成**:
   - 右上の「**+ New**」➔「**Web Service**」をクリック。
   - GitHub リポジトリ `shidukay2-lgtm/stock-trading-system` を選択。
4. **設定内容**:
   - **Name**: `stock-trading-system`
   - **Region**: `Singapore` (シンガポール)
   - **Branch**: `main`
   - **Runtime**: `Node` (または `Docker`)
   - **Build Command**: `pip install -r requirements.txt && python server/market_monitor.py`
   - **Start Command**: `node server.js`
   - **Plan**: `Free`
5. **デプロイ完了**:
   - 数分でビルドが完了し、`https://stock-trading-system.onrender.com` が発行されます。
   - スマートフォン（iPhone Safari / Android Chrome）でこのURLを開くだけで、リアルタイム相場監視・シグナル通知・手動エントリー管理がどこからでも行えます！

## 🚀 ローカル起動方法

- **最も簡単（ダブルクリック）**: `start.bat` を実行
- **Node.js**: `npm start` (http://localhost:3000)
- **Python**: `python main.py --web`
